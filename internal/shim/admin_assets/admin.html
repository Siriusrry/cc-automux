Live routing

AnyRouter

Two entrances front the same backend — traffic sticks to the live one and fails over only on error.

The shim owns upstream auth. Whatever key you set in Claude Code's settings.json is ignored.

Session-sticky. Each session keeps one account to maximize cache hits; new sessions spread across healthy accounts. An account is evicted only after it keeps erroring, then cools down before rejoining.

CPA

CLIProxyAPI upstream. One key, no rotation — the shim still signs the request, so Claude Code's settings key is ignored here too.

Classifier interception

Where auto-mode security-monitor requests go. The rewrite is chosen by the request's model — Claude or GPT.

auto matches the URL against your AnyRouter / CPA upstreams; pick a platform to force the classifier fix.

Classifier requests to CPA always run on a fresh, isolated session id.

Service

Process binding. The host is fixed to loopback.
